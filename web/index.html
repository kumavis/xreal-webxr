Open stereo/head-tracking test

  1. Load extension/dist as an unpacked extension in Chrome or Brave.
  2. Reload this page. Click Connect in the XREAL toolbar.
  3. Hold the glasses still for two seconds to calibrate.
  4. Click Stereo mode; macOS should show the glasses as 3840 × 1080.
  5. Move the browser window onto the glasses display, go Fullscreen, and enter VR.

Exit XR, then Mirror mode returns the glasses to an ordinary monitor. Ctrl-C in the helper also restores the initial mode.
